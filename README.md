# Alex-stampede Tap

## How do I install these formulae?

`brew install alex-stampede/tap/<formula>`

Or `brew tap alex-stampede/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "alex-stampede/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
